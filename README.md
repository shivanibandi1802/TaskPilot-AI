# 🚀 TaskPilot AI — Intelligent Productivity Cockpit

An intelligent, zero-setup task management and productivity suite built with modern web technologies, offline persistence, procedural Web Audio synthesis, and an autonomous AI Copilot.

---

## ✨ Features

- **⚡ AI Copilot & Goal Deconstruction**:
  - Enter high-level goals (e.g., *"Train Machine Learning Model"*, *"Prepare for final exams"*), and TaskPilot AI automatically decomposes them into structured, actionable milestones with priority and time estimates.
  - **Natural Language Quick-Add**: Type naturally like *"Submit lab report tomorrow 4pm urgent"* to automatically extract due date, priority, and task title.
  - **Daily Velocity Briefing**: Real-time standup recommendations and focus coaching.

- **📋 Kanban Board**:
  - 4 workflow stages: **To Do**, **In Progress**, **In Review**, **Completed**.
  - Drag-and-drop card movements with celebration confetti on completion.
  - Subtask checklists and progress tracking bars.

- **🎯 Eisenhower Matrix**:
  - Visual decision triage into **Q1 (Do First)**, **Q2 (Schedule)**, **Q3 (Delegate)**, and **Q4 (Eliminate)**.

- **⏱️ Pomodoro Focus Companion**:
  - Deep Focus (25m), Short Break (5m), and Long Break (15m) sessions.
  - Links directly to tasks to log time spent.
  - **Procedural Ambient Audio**: Synthesizes **Gentle Rain** and **6Hz Theta Binaural Beats** in real-time via the HTML5 Web Audio API (100% offline, no external audio files required).

- **📊 Velocity & Productivity Analytics**:
  - Weekly throughput velocity charts.
  - Priority load distribution and project share metrics.

- **💾 Data Portability**:
  - LocalStorage persistence.
  - One-click **Export to JSON** backup.
  - One-click **Markdown Productivity Report** generator.
